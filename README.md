# reviewbot

`reviewbot` is a specification-first GitHub-native code review and coding-agent bot.

## Status

Incomplete Milestone 0 scaffold. The action, CLI, config parser, policy skeleton,
and validation tests are being built from `SPEC.md` and `PLAN-reviewbot-implementation.md`.

## Validation

```bash
bun install
bun run typecheck
bun run lint
bun test
bun run build
```
